How to install

These steps are for the official Minecraft Launcher on Windows. It takes about 5 minutes.

  1. Install Fabric

    Run the Fabric installer, choose the Client tab, pick Minecraft 26.1.2, and click Install.

  2. Open your mods folder

    Press Windows + R, type %appdata%\.minecraft and press Enter. Open the mods folder, or create one called mods if it isn't there.

  3. Add the two mods

    Put Fabric API and EssenceSMP.jar into the mods folder.

  4. Launch Fabric

    Open the Minecraft Launcher, choose the fabric-loader-26.1.2 profile next to the Play button, and click Play.

  5. Make a new world

    Create a world and join it. The ritual plays and gives you a random essence. Use /essence to open your essence menu.

Questions

Do I need this mod to play on the server?

No. The server works with normal Minecraft. This mod is only for playing essences in your own singleplayer worlds.

Minecraft crashes or the mod doesn't load

Check that you're using the fabric-loader-26.1.2 profile, that Fabric API is in your mods folder, and that both are made for Minecraft 26.1.2.

Can I play it with friends?

For the full experience with sparks and limited gear, join the server at play.remismp.online.
